O que faz

Um dialeto claro do Luau

Cada construção em português vira a instrução Luau equivalente. O contexto (servidor, cliente ou comum) vem da classe do Script — não do texto.

⌨

Português → Luau puro

O Source gerado é Luau normal. Abra, leia, edite e versione — nada de código ofuscado ou motor interpretado.

◧

Contexto automático

Script é servidor, LocalScript é cliente, ModuleScript é comum. O mesmo comando se adapta ao lugar onde roda.

✦

Gameplay e interface

Eventos, laços, funções, tabelas, animações, formas, UI, câmera e comandos prontos como causar dano e teleportar.

Um script inteiro

Menu com botão, animação, espera e controle de câmera — escrito em português e compilado para Luau.

YashScript
usar "Jogar" = StarterGui.Menu.Jogar
usar "Camera" = workspace.CurrentCamera

quando iniciar
    Camera.CameraType = Scriptable
fim

quando mouse_em "Jogar"
    animar("Jogar") crescer + escala = 1.4
fim

quando clicar "Jogar"
    esperar 0.5
    esconder StarterGui.Menu
fim
Luau gerado
local Jogar = StarterGui.Menu.Jogar
local Camera = workspace.CurrentCamera

Camera.CameraType = Enum.CameraType.Scriptable

Jogar.MouseEnter:Connect(function()
    TweenService:Create(Jogar, TweenInfo.new(0.3), {
        Size = Jogar.Size * 1.4
    }):Play()
end)

Jogar.MouseButton1Click:Connect(function()
    task.wait(0.5)
    StarterGui.Menu.Visible = false
end)
Nota: os trechos acima ilustram o estilo do Luau gerado. O Source real é produzido pelo compilador do plugin, com os nomes reais dos objetos.
