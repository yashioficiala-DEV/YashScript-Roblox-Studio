Uma linguagem em português
para vários alvos.

YashScript é uma linguagem de programação em português com portes independentes. Escreva uma vez e rode no Roblox Studio (gera Luau puro) ou na Engine Web/Nativa (motor 2D no navegador) — e o que vier depois.

Portes

Um núcleo, vários alvos

O port é a implementação da linguagem num ambiente. Hoje: o plugin do Roblox Studio e a Engine Web/Nativa.

Ver detalhes dos portes
O que faz

Um dialeto claro e em português

Construções em português para variáveis, condições, laços, funções, eventos, formas e UI. Cada porte traduz o mesmo núcleo para o seu alvo.

⌨

Código legível

Escreva comandos em português: quando clicar, criar bloco, rgb(), para cada. Nada de símbolos crípticos.

◧

Múltiplos alvos

O mesmo núcleo da linguagem alimenta portes diferentes: o plugin gera Luau; a engine interpreta nativamente no canvas.

✦

Gameplay e interface

Eventos, laços, funções, tabelas, animação, formas, UI, câmera e comandos como causar dano e teleportar.

Um script inteiro

Menu com botão, animação, espera e controle de câmera — escrito em português e compilado para Luau.

YashScript
usar "Jogar" = StarterGui.Menu.Jogar
usar "Camera" = workspace.CurrentCamera

quando iniciar
    Camera.CameraType = Scriptable
fim

quando mouse_em "Jogar"
    animar("Jogar") crescer + escala = 1.4
fim

quando clicar "Jogar"
    esperar 0.5
    esconder StarterGui.Menu
fim
Luau gerado
local Jogar = StarterGui.Menu.Jogar
local Camera = workspace.CurrentCamera

Camera.CameraType = Enum.CameraType.Scriptable

Jogar.MouseEnter:Connect(function()
    TweenService:Create(Jogar, TweenInfo.new(0.3), {
        Size = Jogar.Size * 1.4
    }):Play()
end)

Jogar.MouseButton1Click:Connect(function()
    task.wait(0.5)
    StarterGui.Menu.Visible = false
end)
Nota: os trechos acima ilustram o estilo do Luau gerado. O Source real é produzido pelo compilador do plugin, com os nomes reais dos objetos.
