YashScript V8

Guia de referência da linguagem para criar scripts no Roblox. Pesquise uma palavra, selecione-a e veja para que serve, como escrever e um exemplo direto.

Comece por aqui

Uma linha por instrução

Escreva comandos em linhas separadas. Use # para comentários e feche cada bloco com fim.

Declare referências

usar dá um nome curto a um serviço, objeto ou propriedade do Roblox.

Escolha o script certo

Interface e eventos de mouse rodam no cliente: use um LocalScript. A classe do script define o contexto.

Exemplo: botão de menu

O botão cresce quando o cursor entra e volta ao tamanho normal quando sai. Coloque o código em um LocalScript e crie o botão no mesmo script: um alvo de evento só resolve se ele for criado aqui ou declarado com usar.

criar botao "Jogar"
    texto = "Jogar"
    posicao = (0, 0, 0)
    tamanho = (180, 52)
fim

quando mouse_em Jogar
    animar("Jogar") crescer + escala = 1.08 + duracao = 0.15
fim

quando mouse_sair Jogar
    animar("Jogar") diminuir + escala = 1 + duracao = 0.15
fim

quando clicar Jogar
    print("Começando")
fim

Variáveis e expressões

Declare valores reutilizáveis e combine números, texto e referências. A variável fica disponível nos comandos e eventos do mesmo script.

variavel Base = 2
variavel Multiplicador = 3
variavel Total = Base + Multiplicador * 4
variavel Mensagem = "Total: " .. Total

se Total > 10 e Base >= 2
    print(Mensagem)
fim

Funções, parâmetros e retorno

Crie uma função reutilizável, receba valores pelos parâmetros e devolva um resultado com retornar. Variáveis declaradas em funções, ações e callbacks de evento são locais e começam de novo a cada execução. A função pode ser chamada em uma expressão ou sozinha para executar comandos.

criar funcao Somar(a, b)
    retornar a + b
fim

variavel Total = Somar(2, 3)
Somar(Total, 4)

Listas e tabelas

Use chaves para criar uma tabela. Valores sem chave formam uma lista; pares nome = valor formam campos nomeados. Acesse posições numéricas ou chaves calculadas com colchetes e campos nomeados com ponto.

variavel Inventario = {"espada", "escudo"}
variavel Dados = {pontos = 10, ganho = 2}
Inventario[2] = "lanca"
Dados["pontos"] += Dados.ganho

Laços e coleções

para percorre um intervalo inclusivo. para cada percorre listas com ipairs; com dois nomes, percorre chaves e valores de um mapa com pairs. repita ... ate executa pelo menos uma vez e verifica a condição no final. Use pare para sair do laço atual e continuar para pular para a próxima repetição.

variavel Dados = {pontos = 10, ganho = 2}

para indice de 1 ate 5 passo 2
    print(indice)
    se indice == 3
        pare
    fim
fim

para cada chave, valor em Dados
    print(chave)
    print(valor)
fim

Câmera fixa em uma peça

Em um LocalScript, marque a câmera como Scriptable e copie o CFrame de uma peça chamada CameraPart. O exemplo completo inclui a volta ao controle normal quando o jogador clica em Jogar.

usar "Camera" = workspace.CurrentCamera
usar "CameraPart" = workspace.CameraPart

quando iniciar
    Camera.CameraType = Scriptable
    Camera.CFrame = CameraPart.CFrame
fim

Números e textos

Números aceitam notação científica, com ou sem sinal no expoente. Sem valor à esquerda, e é expoente; entre dois valores, e é o operador lógico, então 1 e -7 continua sendo uma expressão lógica. Textos aceitam acentos em UTF-8 direto e os escapes de aspa, barra invertida, quebra de linha, retorno de carro, tabulação e código decimal de 3 dígitos.

variavel Pequeno = 1e-7
variavel Grande = 2.5E+3
variavel Aviso = "linha 1\nlinha 2"
print(Aviso, Pequeno, Grande)

Cores

Use sempre rgb(r, g, b) para cores. Entre nomes, o gerador só traduz preto e branco (e black/white), e apenas nas propriedades cor, cor_texto, cor_borda e fundo. Qualquer outro nome, como vermelho ou azul, não é traduzido: vira uma string inválida em elementos de interface e é descartado em formas 3D.

criar painel "Aviso"
    cor = rgb(40, 60, 90)
    cor_texto = branco
    cor_borda = rgb(90, 110, 140)
    arredondamento = 8
    largura = 320
    altura = 80
fim

Limitações conhecidas do V8

Estes pontos foram verificados contra o gerador atual e vale conferir antes de usar:

jogador é só sujeito lógico. Ele funciona em quando jogador tocar, e o corpo do handler recebe _YashPersonagem, que é o Model do personagem, não o Player. Em qualquer outra posição, é um nome comum: declare-o com usar "jogador" = ... ou criar objeto 'jogador'.

Não há alias pronto para o jogador local. Players.LocalPlayer gera Players:WaitForChild("LocalPlayer"), que não funciona, porque LocalPlayer é uma propriedade do serviço e não um filho. O nome solto LocalPlayer também não é resolvido.

Retorno de método não é suportado. Uma chamada como T:find("b"), que devolve dois resultados, não pode ser usada como valor.

incluir depende do host. O plugin do Studio não lê arquivos do computador, então incluir "arquivo.yash" só resolve se o compilador receber o conteúdo do arquivo.

Removidos em V8 por não terem tradução: principal, servidor no início do arquivo, o sufixo YASHSCRIPT: servidor ou YASHSCRIPT: cliente, transicao, controlavel e sombra. Agora dão erro explícito em vez de serem descartados em silêncio. O contexto do script sempre veio da classe do Script no Studio, nunca do texto.
